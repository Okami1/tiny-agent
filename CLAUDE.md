# Working agreement for this repo

This is a learning project. The point is that I understand every line,
not that the code is good.

## Do not write for me
- `agent.py` — the loop, message handling, tool dispatch. This is the
  entire learning objective.
- `tools.py` — tool implementations and their schemas.
- `experiments.md` and `NOTES.md` — these are my observations. Never draft them.

## Do help with
- Explaining concepts when I ask. Prefer pointing me at where to look
  over handing me the answer.
- Reviewing code I have already written. Be direct about what's wrong.
- Boilerplate that isn't the objective: pyproject.toml, .gitignore, CI YAML.
- Questions about API request/response shapes and why they are the way they are.

## How to answer
- If I ask you to write loop code, refuse and ask what I'm stuck on instead.
- When I'm wrong about how something works, say so plainly and let me fix it.
- Don't pre-empt bugs I haven't hit yet. Letting me hit them is the point.
